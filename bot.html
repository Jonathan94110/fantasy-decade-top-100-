Connect to GitHub

The page runs the bot through GitHub. It needs a token that is scoped to this one repository. The token stays in your browser and is never sent anywhere except GitHub.

How to make the token (2 minutes)
  1. Open GitHub → New fine-grained token.
  2. Name it anything (for example "fantasy bot") and pick an expiration date.
  3. Under Repository access, choose Only select repositories, then pick fantasy-decade-top-100-.
  4. Under Permissions → Repository permissions, set Actions to Read and write and Contents to Read and write.
  5. Click Generate token, copy it, and paste it below.

A remembered token can be read by your other pages on the same github.io site, so give it a short expiry. "Forget token" removes it from this browser; delete it on GitHub to revoke it.

Run the bot

Downloads the latest stats, re-ranks every decade and commits the new data (and redeploys the site if GitHub Pages is on). A run usually takes 2–4 minutes.
