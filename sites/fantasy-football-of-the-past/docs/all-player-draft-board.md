# All-player draft board

This update is included in the authorized private release of the existing Site. Normal new drafts use one all-era pool. Existing scored contracts remain unchanged; the narrow unscored-draft migration preserves teams, order and picks without resetting the game.

Solo and online draft boards open with **All positions** and **All eras**. Position, era, name/team search, and sorting are optional. Clear player filters restores the complete unfiltered available pool. Every matching row is rendered in the existing scrollable list; no row cap hides the rest. Counts show both the filtered list and total available pool. Position labels identify mixed-position rows.

Fresh 11-player draft pools contain **429 Strict** or **1,308 Historical** eligible actors, including all 40 existing kickers. Historical puts verified older and modern players on the same board. Strict retains its original catalog and verified scoring requirements. Solo's minimum verified-game gate now follows its existing authoritative pick rule: 17 games for a full-season contract, or the original one-game threshold for legacy six-pick drafts. Owned actors are excluded, and existing roster feasibility, legal-only filtering, turn authority and saved scoring contracts remain enforced. Counts shrink as players are drafted.

Quick matchups also open with all positions and all eras. Browsing is separate from starter-slot selection. All-position picks fill an eligible empty slot without silently narrowing the browser to the next slot; choosing a specific slot retains the existing position-by-position flow. The mobile view opens the player pool. Quick contracts retain their supported starter positions, so kickers remain exclusive to the seasons that enable them. The explicit ten-row pagination exposes the full result count and reachable pages: fresh Strict has 395 actors over 40 pages; Historical has 1,268 over 127 pages. Clear restores the full pool and first page.
